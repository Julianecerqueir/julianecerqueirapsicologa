# julianecerqueirapsicologa
Projeto de desenvolvimento do site institucional de **Juliane Cerqueira, Psicóloga Clínica**, com o objetivo de apresentar sua atuação profissional, abordagem terapêutica, serviços e conteúdos relacionados à psicologia, à Terapia Cognitivo-Comportamental (TCC) e ao comportamento humano.

# Objetivos do projeto

- Construir uma presença digital profissional, confiável e acessível.
- Apresentar informações sobre a atuação e os serviços de psicoterapia.
- Facilitar o acesso aos canais de contato e agendamento.
- Organizar conteúdos para diferentes etapas da jornada do visitante.
- Desenvolver uma estrutura semântica que facilite a compreensão do site por mecanismos de busca e sistemas de inteligência artificial.

# Tecnologias utilizadas

- HTML5 semântico.
- CSS3 responsivo.
- JavaScript.
- Schema.org com JSON-LD.
- Metadados SEO e Open Graph.
- Sitemap XML.
- Robots.txt.
- Llms.txt.

# Estrutura e funcionalidades

O projeto contempla cinco páginas HTML, navegação interna, menu responsivo, integração com canais de contato, identificação de autoria, links para redes sociais e estrutura preparada para expansão.

Também considera acessibilidade, desempenho, organização do código, experiência em dispositivos móveis e boas práticas de privacidade e proteção de dados (LGPD).

# Identidade visual

A identidade visual utiliza azul-marinho, dourado e tons claros, buscando transmitir profissionalismo, clareza, acolhimento e confiança.
